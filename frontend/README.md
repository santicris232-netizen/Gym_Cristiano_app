# Gym Cristiano App — frontend

React + Vite + TypeScript + Tailwind CSS. Ver el README en la raíz del
repo para las instrucciones completas de puesta en marcha (backend +
frontend) y la descripción del proyecto.

```bash
npm install
npm run dev
```

Abre en [http://localhost:5173](http://localhost:5173). El backend
(FastAPI) debe estar corriendo en `http://localhost:8000` — Vite
proxea `/api/*` hacia ahí en desarrollo (ver `vite.config.ts`).
